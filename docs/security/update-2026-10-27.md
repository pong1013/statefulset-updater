`requirements.in` records direct dependency inputs and HTTP security floors; `requirements.txt` locks all 27 resolved runtime packages. Kubernetes remains 26.1.0. Flask advances to 3.1.3, requests to 2.34.2, urllib3 to 2.8.0, and Werkzeug to 3.1.9. Dependencies were resolved and installed using real Python 3.13, including wheel availability on arm64.

`requirements-build.txt` separates pip, wheel and packaging installer tools from the application lock. Images use patched pip 26.2.2 during installation, then remove pip, wheel and packaging plus the standard-library ensurepip package and its bundled pip wheel from the final runtime filesystem. Patched setuptools 84.2.1 remains in the runtime lock because Kubernetes 26 explicitly declares it as a dependency; removing it would fail `pip check`.

CI installs the real locked packages on Python 3.13, checks dependency consistency, runs the independent installed-library integration tests with the existing suite, and audits the runtime lock using pip-audit 2.10.1 in a separate environment.
