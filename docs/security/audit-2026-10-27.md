## Images and priorities

All three Dockerfiles use python:3.9 and install the same requirements.txt. Python 3.9 reached EOL on 2025-10-31: https://devguide.python.org/versions/ . Move to a supported Python 3.13 slim-trixie security revision, pull fresh bases during builds, and pin the verified digest. Slim reduces bundled packages but does not guarantee absence of vulnerabilities. Official tags: https://hub.docker.com/_/python .

Update requests and urllib3 together: requests 2.28.2 constrains urllib3 below 1.27. urllib3 1.26 patch upgrades cannot cover all current advisories. Prioritize TLS/HTTP dependencies and Flask/Werkzeug. Resolve pyasn1-modules/google-auth with pyasn1 and requests-oauthlib with oauthlib. kubernetes 26.1.0 had no matches in this audit; client updates still require target-cluster compatibility review.

Separate pip/setuptools/wheel from runtime requirements; current pins downgrade build tooling. Build-tool advisories often require malicious package sources or installation and do not prove remote exploitation of the webhook.

Some Werkzeug advisories require Windows/NTFS, which does not match these Linux images. Debugger exploitation has additional conditions; app.debug is False. The webhook processes JSON, so multipart DoS reachability is not established. Flask session/cache and OAuth server PKCE issues also require feature-specific assessment.

Helm image repository/tag values are deployment inputs; appVersion 1.16.0 does not establish a deployed image identity or Kubernetes version. No deployed digest or original scanner report was provided. Local Docker socket access was denied; no image OS scan was completed. The smoke-test workload uses busybox:1.36; select and scan an updated test image separately.

After updating, run existing unit tests, Helm checks and local k3s smoke tests. Rebuild all three application images, scan OS and Python packages in each final digest, then deploy new images. No runtime dependencies or deployments were changed by this audit.

pip-audit -r requirements.txt --format json --output dependency-audit.json
